EBIZCO Australia is seeking a manufacturing partner to supply MULTIPLE
smart lock mechanical base unit types for retrofit with our proprietary

Full firmware stack

Unified mobile app and cloud server platform

WHAT WE REQUIRE FROM SUPPLIER:

NO wireless module (Tuya/TTLock) — socket must be left EMPTY

6. TECHNICAL REQUIREMENTS (ELECTRONIC LOCKS)
===============================================================================

6.1 ELECTRONIC INTERFACE (COMMON ACROSS ALL TYPES)
---------------------------------------------------
+----------------------------------------+----------------------------------------+
| Requirement                            | Specification                          |
+----------------------------------------+----------------------------------------+
| Host MCU                               | Factory-standard microcontroller        |
| Communication                          | Plaintext UART (TX/RX)                  |
| Protocol                               | Standard Tuya MCU Serial Protocol       |
|                                        | (0x55 0xAA headers, 8-bit checksum)     |
| Wireless module                        | Socket left EMPTY                       |
| Connector                              | 4-pin JST-PH compatible                 |
|                                        | (VBAT_IN, GND, TX, RX)                  |
+----------------------------------------+----------------------------------------+

IMPORTANT POWER NOTE (VCC):
The 4-pin JST connector shall carry RAW BATTERY VOLTAGE
(typically 4.5V - 6.5V for 4x AA batteries, 3.6V minimum)
on the "VCC" pin, NOT the host MCU's regulated 3.3V output.

REASON: Our daughterboard ESP32-C6 consumes up to 350-400mA
during Wi-Fi 6 / Thread TX bursts. The host MCU's 3.3V rail
is typically current-limited (<100mA) and will cause brownouts.

Our daughterboard includes a dedicated, ultra-low-Iq (<10µA)
LDO regulator that handles the peak current from the raw battery
input. This ensures both the host MCU and our module have
stable, independent power supplies.

The signal lines (TX, RX, SRDY, MRDY) remain at 3.3V logic
levels compatible with the host MCU.

===============================================================================

6.2 POWER SUPPLY INTERFACE (SUPPLIER MUST ROUTE)
------------------------------------------------

The factory PCB MUST route the following connections to the
4-pin JST-PH header (or equivalent footprint) where our
daughterboard plugs in:

+----------+----------+---------+----------------------------------------+
| Pin      | Signal   | Voltage | Requirement                            |
+----------+----------+---------+----------------------------------------+
| 1        | VBAT_IN  | 3.6V-6.5V| RAW battery voltage. Trace width >=   |
|          |          | (DC)    | 25 mil to support 500mA peak current. |
|          |          |         | Bypass capacitors (>= 10uF) optional  |
|          |          |         | on this line.                          |
| 2        | GND      | 0V      | Common ground. Trace width >= 25 mil. |
| 3        | TX       | 3.3V    | Module -> MCU (full-duplex).           |
|          |          |         | Connect to host MCU UART RX pin.       |
| 4        | RX       | 3.3V    | MCU -> Module (full-duplex).           |
|          |          |         | Connect to host MCU UART TX pin.       |
+----------+----------+---------+----------------------------------------+

Optional (Keep-Alive Handshake, per Tuya standard):

+----------+----------+---------+----------------------------------------+
| Signal   | Direction| GPIO    | Description                            |
+----------+----------+---------+----------------------------------------+
| SRDY     | MCU->Mod | GPIO3   | MCU wakes module (active low)          |
| MRDY     | Mod->MCU | GPIO20  | Module wakes MCU / has data (active lo)|
+----------+----------+---------+----------------------------------------+

===============================================================================

6.3 POWER CONSUMPTION GUIDELINES (FOR FACTORY PCB DESIGN)
--------------------------------------------------------

+----------------------------------------+----------------------------------------+
| Component                              | Peak Current (Typical)                  |
+----------------------------------------+----------------------------------------+
| Host MCU + Keypad + Fingerprint        | 30-50mA @ 3.3V                         |
| Motor (unlocking burst)                | 200-300mA @ 6V (sourced separately)     |
| Daughterboard ESP32-C6 (Wi-Fi TX)      | 350-400mA @ 3.6V (after LDO)            |
+----------------------------------------+----------------------------------------+

CRITICAL DESIGN RULE:
The host MCU's 3.3V rail MUST NOT be used to power our daughterboard.
The daughterboard receives its power DIRECTLY from the raw battery
input (VBAT_IN) on the JST connector. This prevents brownouts
during simultaneous operations (e.g., motor + Wi-Fi TX).
